# AMI100：手动运行的完整对照

所有新生成组固定同一份 `input/experiment_1_unfiltered_cap100/ami.jsonl`，每组最多 100 条，
不新设长度过滤，不插入挑战事项。该文件为之前实验使用的 AMI 导出，不声称是未见会议或官方测试划分。
以下是独立指令，按顺序执行，不要并行运行多个生成组。
若希望前一步结束自动执行下一步，使用 [TASK_QUEUE.md](TASK_QUEUE.md) 的串行队列入口。

## 1. 配置输入和同一模型快照

```bash
conda activate latent-agents
cd /root/autodl-tmp/Latent-communication-meeting_summary

INPUT=input/experiment_1_unfiltered_cap100/ami.jsonl
RUN_ROOT=test_result/experiment_3_ami100_v3_seed12

MODEL=$(python -c "from huggingface_hub import snapshot_download; print(snapshot_download('Qwen/Qwen3-8B', revision='b968826d9c46dd6066d109eabc6255188de91218', allow_patterns=['*.json','*.safetensors','*.txt','*.jinja']))")
```

这一 commit 来自已保存的旧 Qwen3-8B 控制实验。Hub 缓存可复用；未缓存的文件会下载。
所有组都把同一个 `$MODEL` 快照路径传给模型加载器，避免先下载最新版本再发生 revision 冲突。
变量在当前终端有效；换终端后需要重新设置，或直接填写实际路径。

## 2. 原窗口与 V3：各 100 条

```bash
python -m experiment_3 \
  --input "$INPUT" --benchmark ami \
  --output-dir "$RUN_ROOT/workflow" --num-samples 100 \
  --conditions baseline semantic \
  --model "$MODEL" --device cuda \
  --role-budget-ratio 0.25 --speaker-neighbor-blocks 1 \
  --vector-routing --embedding-model Qwen/Qwen3-Embedding-0.6B \
  --supplement-blocks 2 --exclude-neighbor-blocks 1 \
  --seed 12 --summary-seed 42 \
  --summary-temperature 0.3 --summary-top-p 0.9 --summary-thinking

WORKFLOW_RUN=$(find "$RUN_ROOT/workflow" \
  -mindepth 1 -maxdepth 1 -type d | sort | tail -n 1)
```

这一步共享一次全局选取，独立生成 baseline 和 semantic。两组共同使用语义辅助全局选择；
baseline 指没有 V3 的后选取补充，不是完全关闭 embedding 的组。

## 3. 全文单模型：100 条

```bash
python -m experiment_2 \
  --input "$INPUT" --benchmark ami \
  --output-dir "$RUN_ROOT/direct" --num-samples 100 \
  --model "$MODEL" --device cuda \
  --seed 12 --summary-seed 42 \
  --summary-temperature 0.3 --summary-top-p 0.9 --summary-thinking

DIRECT_RUN=$(find "$RUN_ROOT/direct" \
  -mindepth 1 -maxdepth 1 -type d | sort | tail -n 1)
```

不要使用旧挑战集的 `direct_text` 目录：本步骤是未插入事项的原始 AMI，使用标准实验 2 格式。

## 4. 长度匹配随机补充：100 条，seed 7

```bash
python -m experiment_3.random_control \
  --source-run "$WORKFLOW_RUN" \
  --output-dir "$RUN_ROOT/random_seed7" \
  --num-samples 100 --random-seed 7 --device cuda

RANDOM_RUN=$(find "$RUN_ROOT/random_seed7" \
  -mindepth 1 -maxdepth 1 -type d | sort | tail -n 1)
```

这里不传 `--answer-key`：真实 AMI100 没有预先标注的挑战事项，不计算关键证据共同窗口覆盖率。
仍会报告补充量是否匹配。source workflow 若失败或文件缺失，会跳过并记录，不阻止其他已完成会议重放。
random 只新生成本组，不重跑 baseline、semantic、selectors 或 embedding。

## 5. 一次性评分与配对比较

```bash
python -m experiment_3.evaluate \
  --run-dir "$WORKFLOW_RUN" --direct-run "$DIRECT_RUN" \
  --random-runs "$RANDOM_RUN" \
  --bertscore-model allenai/longformer-base-4096 \
  --bertscore-layers 12 --device cuda

EVAL_DIR=$(find "$WORKFLOW_RUN/evaluation" \
  -mindepth 1 -maxdepth 1 -type d | sort | tail -n 1)

cat "$EVAL_DIR/summary.txt"
```

只读取已生成摘要，加载一次评分模型，不重新生成。所有报告组使用同一个共同完成样本交集；
若并非全部 100 条成功，报告实际配对数以及失败和缺失 ID，不把失败当作零质量分。

| 输出/指标 | 用途 |
|---|---|
| ROUGE-1/2/L | 词面参考相似度；CSV 中包含 P/R/F1 |
| BERTScore P/R/F1 | 语义参考相似度；不是事实正确率 |
| source-support proxy | 词汇来源重叠代理；不是来源事实核查 |
| duplicate diagnostics | 完全相同 bullet 的样本数及多余条目数；不是语义去重率 |
| logical input/output/total tokens | decoder 事件记账；不是计费、网络传输或 FLOPs |
| local/final KV position events | 上下文位置访问记录，与 token 事件、字节分开 |
| pipeline seconds | 原窗口、V3、单模型的已有全流程记录；random 因重放省略步骤而为 N/A |
| paired bootstrap 95% intervals | 每组与单模型，以及 V3 与原窗口/随机组的配对差值 |
| length_groups.csv | 0–4000、4000–8000、8000–12000、12000–16000、16000+ 的样本数和各指标均值 |

`summary.json` 保存完整统计与比较；`per_sample.csv` 保存逐样本数据；`length_groups.csv` 保存分组；
`evaluation_manifest.json` 保存来源文件指纹、随机组关联关系及 BERTScore 配置。
本入口没有 paired CUDA peak 记录，不会假装测到了随机组与其他组的公平显存差异。

## 6. 可选：另外两个随机 seed，各 100 条

第一轮 seed 7 结果冻结后，可预先固定增加 seed 19、43 做随机组稳定性测试。
不要因为结果不理想才换 seed，也不要将 3×100 个结果当成 300 场独立会议。

```bash
RANDOM_RUNS=("$RANDOM_RUN")

for SEED in 19 43; do
  python -m experiment_3.random_control \
    --source-run "$WORKFLOW_RUN" \
    --output-dir "$RUN_ROOT/random_seed$SEED" \
    --num-samples 100 --random-seed "$SEED" --device cuda

  RANDOM_RUNS+=("$(find "$RUN_ROOT/random_seed$SEED" \
    -mindepth 1 -maxdepth 1 -type d | sort | tail -n 1)")
done

python -m experiment_3.evaluate \
  --run-dir "$WORKFLOW_RUN" --direct-run "$DIRECT_RUN" \
  --random-runs "${RANDOM_RUNS[@]}" \
  --bertscore-model allenai/longformer-base-4096 \
  --bertscore-layers 12 --device cuda
```

每个随机 seed 单独显示，比较仍按会议配对。全部方法的均值使用所有传入组的共同完成交集，
因此新加一个失败更多的 seed 时，汇总分母可能缩小，必须一并检查报告中的缺失记录。
此处没有自动事实打分，不需要调用额外语言模型 judge。
